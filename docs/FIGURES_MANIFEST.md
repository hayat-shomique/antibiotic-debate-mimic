## Contract rules

1. Style: import `figures/src/_style.py`; kicker in accent caps plus a declarative claim as the title; direct labels, never a legend; light single-axis grid; one accent colour for the thing the claim is about; PNG at 200 dpi and SVG, every time.
2. Reproducibility: each script reads only result files on disk, prints every headline number to stdout, and hand-enters nothing; a figure that cannot regenerate from disk does not ship, and any figure whose numbers are not final carries the DRAFT watermark.
3. Governance: aggregates only — no patient-level values, no `case_id` / `subject_id` / `micro_specimen_id` on any axis or label; "sycophancy" is retired from headline claims per `framing_ruling.md`; date everything 19 August 2026, never weekday labels.
